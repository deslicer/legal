# Deslicer Security Exhibits

<img src="../media/logo.png" alt="Deslicer logo" width="300" />

This directory is reserved for security exhibits that describe additional security measures applicable to certain Deslicer Offerings, as referenced in section 7.2 of the Deslicer General Terms.

## Purpose

Security exhibits, when published, provide detailed descriptions of security controls, certifications, and practices for specific Offerings. Baseline security requirements are described in section 7 of the General Terms and apply to all Offerings.

## Current Status

At present, no separate security exhibits have been published. The baseline security program described in section 7 (Security) of the General Terms and Annex 2 (Technical and Organizational Measures) of the DPA apply to all Offerings.

When offering-specific security exhibits are published, each exhibit will be added to this directory and will form part of the Specific Offering Terms for the relevant Offering. Customers will be notified when security exhibits become available for their subscribed Offerings.

## Planned Security Documentation

Deslicer plans to publish offering-specific security exhibits as security certifications and formal assessments are completed.

### Baseline SaaS Security Documentation

Deslicer is developing comprehensive security documentation covering:
- Security program overview and governance
- Administrative controls (policies, training, background checks)
- Technical controls (encryption, access control, MFA, logging, monitoring)
- Physical and environmental security
- Incident response and business continuity
- Vulnerability management and patching
- Secure development lifecycle
- Third-party security management
- Compliance and audit framework

### Offering-Specific Security Exhibits

Deslicer plans to develop offering-specific security exhibits for:

**Deslicer AI** - AI-specific security controls, model security, training data protection, prompt injection defenses, LLM provider security requirements, and Bring-Your-Own-LLM security architecture

**Deslicer DevOps** - CI/CD pipeline security, artifact signing and verification, secrets management, deployment approval workflows, and supply chain security measures

**Deslicer Automation Platform** - Configuration data protection, change authorization controls, audit logging, rollback security, policy enforcement, and credential management

### Industry-Specific Documentation

Subject to customer demand, Deslicer may develop industry-specific security documentation for:
- Healthcare (HIPAA compliance, medical device security)
- Financial Services (PCI DSS, GLBA, SOX)
- Public Sector (C5, TISAX, FedRAMP)

## Certifications

Deslicer is evaluating third-party security certifications to provide independent validation of security controls. Certification decisions are driven by customer requirements and industry standards.

Security controls are currently implemented and maintained in accordance with section 7 of the General Terms and Annex 2 of the DPA.

## Requesting Custom Security Documentation

Customers requiring specific security documentation or certifications before these exhibits are published should contact [security@deslicer.com](mailto:security@deslicer.com) to discuss:

- **Custom security documentation under NDA:** Detailed security architecture, controls, and procedures
- **Security questionnaire completion:** Standardized or custom security assessments
- **Customer security audits:** On-site or remote security audits (subject to scope and timing)
- **Certification roadmap discussions:** Specific certifications required for your procurement process

**Response Time:** We typically respond to security documentation requests within 5 business days. Complex requests may require additional time.
