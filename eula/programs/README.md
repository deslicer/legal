## When to Use

- **Beta Program EULA**: Applies when users participate in free pre-release programs that require feedback in exchange for early access. This EULA sets appropriate expectations for experimental features and limited availability guarantees.

## Relationship to Other Terms

Program EULAs work alongside:

- **Product EULAs** (in `../offerings/`): Product-specific terms that reference the applicable base terms
- **General Terms** (in `../../general-terms/`): Base terms for business customers
- **Consumer Terms** (in `../../general-terms/`): Base terms for individual consumers

Users participating in beta programs are governed by the Beta Program EULA, which supersedes the General Terms or Consumer Terms for matters specific to the beta program, while still respecting mandatory consumer rights where applicable.
