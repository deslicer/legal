## Purpose and Usage

This document contains standard warranty disclaimers and limitation of liability provisions that are common across all Deslicer End User License Agreements (EULAs). Individual EULAs reference this module rather than duplicating these provisions, which:

- Reduces maintenance overhead
- Ensures consistency across all product EULAs
- Simplifies future updates to standard terms

**Note:** This is an internal reference document. Product-specific EULAs remain the binding agreements with customers.

## Maintenance Notes

### When to Update This Module

Update this module when:

- Swedish law or GDPR requirements change affecting standard disclaimers
- Case law establishes new precedents for software liability
- Deslicer's legal counsel recommends updates to standard language
- New product categories require additional standard disclaimers

### How to Update

1. Update the relevant module section in this document
2. Review all EULAs that reference the updated module
3. Decide whether to update EULAs immediately or at next major version
4. Document changes in the version history below
5. Notify legal team and product managers of updates

### Cross-Reference Verification

When updating this module, verify consistency with:

- Deslicer General Terms, sections 17 (Warranties) and 18 (Limitation of Liability)
- Specific Terms for each Offering
- DPA liability provisions (section 10)

## Usage Guidelines

### For Product-Specific EULAs

**Do:**
- Reference the appropriate module by name
- Add product-specific disclaimers as supplements
- Link to this document for detailed standard terms
- Keep product-specific disclaimers focused on unique risks

**Don't:**
- Copy-paste entire modules into individual EULAs
- Modify module language in individual EULAs
- Create conflicting disclaimers in product EULAs
- Remove references to General Terms

### Example Reference

In a product EULA:

```markdown
## 4. Warranties and Disclaimers

Warranties are set out in section 17 of the Deslicer General Terms. Standard warranty disclaimers applicable to all Deslicer Offerings are documented in the Standard EULA Disclaimers module at [link].

Additional disclaimers specific to [Offering Name]:

- [Product-specific disclaimer 1]
- [Product-specific disclaimer 2]

For a summary of standard warranty disclaimers and limitations, see Module 1 (AS-IS Warranty Disclaimer) and Module 4 (Limitation of Liability) in the Standard Disclaimers document.
```
